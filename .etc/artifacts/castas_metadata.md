What:	🤬 Castas • Affective Polarization Test

Why:	The purpose of the app is to offer a diagnostic tool for one of the most challenging phenomena in modern democracies: affective polarization. When opening the main page, the user will be able to start the test immediately, without needing to log in or perform any other configuration. To answer the questions, the user must select the option that best represents their personal values and life choices.

Whom:	Application developed for Brazilian citizens, with the possibility of internationalization to other languages/countries.

Which:	Web-based application, online access, on desktop or mobile.

Whose:	License GPL 3.0

Who:	Raul Bras
When:	March / 2026 @ Osasco/SP 🇧🇷 Brasil
Where:	https://github.com/teknolista/castas

How:	Single-page-app in TypeScript, with React, React Router, Tailwind CSS, Shadcn/UI, Framer Motion. Deploy on GitHub Pages.
